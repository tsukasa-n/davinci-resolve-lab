# Fusion Intro

DaVinci ResolveのFusionを使って、
ベクターベースのイントロアニメーションを制作する手順と検証内容をまとめます。

## Goal

参考映像の動きを分析し、
Fusion上でノードを組みながらイントロアニメーションを再構成します。

最終的には、他の動画でも再利用できるように
透明背景・Alpha Channel付きの素材として書き出せる状態を目指します。

## Topics

- DaVinci Resolve
- Fusion
- Motion Graphics
- Vector Animation
- Node Based Compositing
- Alpha Channel
- Transparent Background

## Workflow

1. 参考映像を確認する
2. 動き・タイミング・レイアウトを分析する
3. Fusionで必要な図形やテキストを作成する
4. ノードを接続する
5. Keyframeでアニメーションを設定する
6. 動きやタイミングを調整する
7. 背景を透明化する
8. Alpha Channel付きで書き出す
9. 他の動画上で再利用できるか確認する
