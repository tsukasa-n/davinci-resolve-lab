# Alpha Export

DaVinci Resolveから透明背景の動画を書き出す方法をまとめます。

## Goal

Alpha Channelを保持した動画を書き出し、
他の動画編集ソフトやWeb制作で再利用できる状態にします。

## Topics

- Alpha Channel
- Transparent Background
- Export Settings
- Codec
- DaVinci Resolve

## Workflow

1. 背景を透明化する
2. Alpha Outputを設定する
3. Deliverページを開く
4. Alpha対応Codecを選択する
5. Export Alphaを有効にする
6. 書き出した動画を確認する

## Notes

CodecによってAlpha Channelへの対応状況が異なります。
詳細は今後追記します。
